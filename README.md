# Data Science Projects

This repository contains data analysis and statistical modeling projects completed as part of my coursework at UC Santa Barbara. The projects highlight skills in data cleaning, transformation, visualization, and predictive modeling using R, Python, and SQL. 

## Projects

### 1. Depression Classification (Logistic Regression)
- **Goal:** Predict depression risk based on dietary habits, sleep duration, and stress factors.
- **Dataset:** 27,901 observations of student survey responses.
- **Skills:** Data cleaning, logistic regression modeling, ROC curves, confusion matrices, hypothesis testing.
- **Files:** `depression_analysis.Rmd`, `depression_analysis.pdf`

### 2. IMDb Movies Dataset (Linear Regression)
- **Goal:** Analyze factors affecting movie success and trends in runtime by genre.
- **Dataset:** 7,000+ IMDb movies (1960–2024).
- **Skills:** Data preprocessing, multiple linear regression, interaction terms, residual diagnostics.
- **Files:** `imdb_analysis.Rmd`, `imdb_analysis.pdf`

## Technologies
- R / RStudio (tidymodels, dplyr, ggplot2)
- Python (matplotlib, pandas)
- SQL
- Excel

These projects showcase my ability to derive actionable insights from large datasets and communicate findings effectively.
