# Data Science Projects

This repository contains data analysis and statistical modeling projects completed as part of my coursework at UC Santa Barbara. The projects highlight skills in data cleaning, transformation, visualization, and predictive modeling using RStudio.

## Projects

### 1. Depression Classification (Logistic Regression)
- **Goal:** Predict depression risk based on dietary habits, sleep duration, and stress factors.
- **Dataset:** 27,901 observations of student survey responses.
- **Skills:** Data cleaning, logistic regression modeling, ROC curves, confusion matrices, hypothesis testing.

### 2. IMDb Movies Dataset (Linear Regression)
- **Goal:** Analyze factors affecting movie success and trends in runtime by genre.
- **Dataset:** 7,000+ IMDb movies (1960–2024).
- **Skills:** Data preprocessing, multiple linear regression, interaction terms, residual diagnostics.

### 3. Stock Price Time Series Analysis (SARIMA & GARCH)
- **Goal:** Model and forecast stock price behavior using time series techniques, and analyze volatility dynamics in financial data.
- **Dataset:** Daily opening prices for INFOSYS stock on the National Stock Exchange (2015, 248 observations).
- **Skills:** Time series analysis, stationarity transformation, ARIMA/SARIMA modeling, ACF/PACF interpretation, GARCH modeling, volatility analysis, model diagnostics.
- **Key Insights:**
  - Stock prices followed a **random walk (ARIMA(0,1,0))**, indicating limited predictability.
  - Minimal autocorrelation after differencing, suggesting weak serial dependence.
  - **GARCH modeling showed limited volatility clustering**, with largely stable variance over time.
